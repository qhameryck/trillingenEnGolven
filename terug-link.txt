Zet deze regel in index.html van elke simulatie, net onder <div class="wrap">.
"../" gaat één map omhoog, dus naar trillingen/index.html:

  <a class="back" href="../">← Terug naar Trillingen</a>

En voeg dit blok toe aan de CSS van die simulatie (bv. onder blok 4):

/* Link terug naar het overzicht */
.back {
  color: var(--muted);
  text-decoration: none;
  font-weight: 700;
}

.back:hover {
  color: var(--fg);
}
